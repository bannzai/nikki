# Handoff: Nikki — iOS 日記アプリ UI

## Overview
Nikki は「誰にも見られない安心設計」を核とする、静かでシンプルな日記アプリ。データは端末内で E2E 暗号化され、開発者も中身を読めない。AI/文章補助・ソーシャル/共有機能は一切なし。本ハンドオフは **iOS(モバイルネイティブ)版の全画面デザイン**をカバーする(Web / macOS は今後展開予定)。

デザインコンセプトは **「白い紙と墨」**。彩色は原則ユーザーのテーマ機能に譲り、UI 自体はほぼ無彩色に保つ。ユーザーが背景色・背景画像で装飾したときに UI が主張しない「器」であることを最優先する。**ダークモードは対象外**(ライトのみ)。

## About the Design Files
このバンドルに含まれる `Nikki iOS.dc.html` は、**HTML で作成されたデザインリファレンス**である。意図した見た目と挙動を示すプロトタイプであり、そのまま本番コードにコピーするものではない。

タスクは、これらの HTML デザインを **ターゲットの iOS 環境(SwiftUI 推奨)で、その環境の確立されたパターン・ライブラリを用いて再現すること**。React Native 等の既存クロスプラットフォーム基盤がある場合はそれに合わせる。環境がまだ無い場合は、ネイティブ iOS として **SwiftUI** を選ぶのが最も自然。

HTML は React ベースの「Design Component」形式で、iPhone フレーム(`ios-frame.jsx`)の中に各画面を配置している。フレーム自体はプレビュー用のスキャフォールドであり、実装対象は各画面の中身。

## Fidelity
**High-fidelity (hifi)。** 最終的な配色・タイポグラフィ・余白・角丸・インタラクションを含む。下記のデザイントークンと各画面仕様に従ってピクセル単位で再現すること。ただし色は意図的にほぼ無彩色なので、ターゲット環境のセマンティックカラー(system background 等)にマップしても良い。

### テーマ用「紙の色」プリセット(テーマ設定画面)
白 `#FFFFFF` / 生成(きなり)`#F7F4EC` / 薄鼠 `#ECECEA` / 青磁 `#E9EDEA` / 桜鼠 `#F2EAE4`。
これらはユーザーが選ぶ画面地の色。UI 前景色(墨・鈍・灰)は据え置きで、地色だけ差し替わる想定。

### Typography
- **UI/本文フォント**: `Zen Kaku Gothic New`(Google Fonts, weights 400/500/700)。フォールバック: `Hiragino Kaku Gothic ProN`, system-ui。実装では San Francisco / Hiragino Sans でも可だが、Zen Kaku Gothic New 指定を第一候補とする。
- **等幅**: `ui-monospace, Menlo, monospace`。復元フレーズの単語、`{{変数}}`、markdown プレビュー、日時ラベルに使用。
- スケール(px, iPhone 論理幅 390–402 想定):
  - 画面タイトル(Nikki ロゴ / ナビ中央): 20px / 700
  - オンボ大見出し: 24–30px / 700 / line-height 1.65
  - 日記タイトル(エディタ本文の H1): 22px / 700
  - リスト項目タイトル: 15px / 700
  - 本文: 15px / 400 / line-height 2.05(エディタ)、13px/1.8(一覧の抜粋)
  - 補助・キャプション: 12–13px、色は鈍/灰
  - mono: 11.5–14px
- 本文は日英混植前提。`text-wrap: pretty` 相当の折り返し配慮。

### Spacing / Radius / Shadow
- 画面横パディング: 24–28px
- カード角丸: 14px、入力フィールド 10–12px、セグメント 9–11px、主ボタン(pill)27px(高さ54px)、FAB 29px(58×58)、モーダル上端 24px
- カード影(通常): `0 1px 3px rgba(0,0,0,.06)`(ほぼフラット)
- フローティングツールバー影: `0 8px 26px rgba(0,0,0,.14)`
- FAB 影: `0 10px 24px rgba(28,27,26,.28)`
- ドラッグ中ブロック影: `0 18px 44px rgba(28,27,26,.22)` + `rotate(-1.2deg) scale(1.02)`
- ボトムシート影: `0 -12px 40px rgba(28,27,26,.18)`

## Screens / Views

### 1. オンボーディング(4ステップ)
初回起動 → 暗号化の説明 → 復元フレーズのバックアップ → Face ID/passkey 登録。トーンは「怖くない安心感」。専門用語より比喩(「鍵のかかった、あなただけの箱」「12の言葉が合鍵になります」)。図解は 46px 円の中にライン SVG アイコン(ペン=書く / 南京錠=鍵をかける / 虫眼鏡=読めるのはあなただけ)。

- **1a ようこそ**: 中央に 52px 角丸枠のロゴ「日」+「Nikki」。大見出し「ここに書くことは、あなたしか読めません。」下部に主ボタン「はじめる」+ テキストリンク「以前の日記を復元する」。
- **1b 暗号化の図解**: ステップインジケータ `1 / 3`(mono, 灰, letter-spacing .15em)。3項目の縦リスト(アイコン円 + タイトル + 説明)。脚注「AI も、解析も、共有もありません。ただの日記帳です。」主ボタン「次へ」。
- **1c 復元フレーズ バックアップ**: `2 / 3`。12単語を 2列グリッド(番号 mono 灰 + 単語 mono 500)。各セルは白カード角丸10px。「スクリーンショットではなく、紙がおすすめです」注記。主ボタン「書き留めました」+ リンク「あとで設定する」。単語例: river, lantern, quiet, marble, orbit, velvet, cedar, hollow, amber, drift, plume, stone。
- **1d フレーズ確認**: 3/7/11番目を順に選ばせる。埋まったスロットはチェック付き、選択中は墨枠+カーソル、未入力は「･･･」。下部に単語チップ(選択済みは打ち消し線+無効)。確認ボタンは全部埋まるまで disabled(`#DBDAD5`)。
- **1e Face ID/passkey 登録**: `3 / 3`。中央に 86px の Face ID 風 SVG(角丸フレーム + 目・鼻・口のライン)。大見出し「つぎからは、顔だけで。」主ボタン「Face ID を有効にする」+ アウトライン「パスキーを登録する」。

### 2. ロック画面(1f)
5秒無操作で自動ロック。背景に日記本文をスケルトン化して `filter: blur(7px); opacity:.55` で表示(中身を守る演出)。中央に 64px 南京錠アイコン円(半透明地)、「鍵をかけておきました」「しばらく手が止まっていたので、そっとロックしました。」墨の pill ボタン「Face ID で開く」(Face ID SVG 付き)。脚注「解除すると、さっきの続きに戻ります」。**解除後は最後に開いていた画面へ復帰**。

### 3. ホーム / 日記一覧(1画面完結)
タブバー無し。上部に Nikki ロゴ + アカウント/設定アイコン、その下に検索バー(くぼみ地 `#F0EFEA`, 高さ42px, プレースホルダ「日記をさがす」)、その下に **セグメントコントロール「リスト / カレンダー」**。右下に FAB(58px 墨円, ペン SVG)= 新規作成。

- **1g 時系列リスト**: 月見出し(12px/700 灰)配下に行を並べる。各行 = 左に日付ブロック(日 21px/700 + 曜日 11px 灰, 幅44px)、右にタイトル(15px/700)+ 抜粋2行(`-webkit-line-clamp:2`, 鈍色)。行間は 0.5px セパレータ。
- **1h カレンダー**: 月送り(‹ 2026年7月 ›)、曜日ヘッダ(日〜土, 灰)、日付グリッド。**書いた日は日付下に 4px 墨ドット**。今日(18)は 36px 墨円で反転表示。未来日は `#C7C6C2`。下にその日の日記プレビューカード(日付+時刻+タイトル+抜粋2行)。FAB 共通。

### 4. エディタ(最重要)
Markdown 互換。ツールバーは **選択時だけ現れるフローティング**方式(常設バー無し)。上部は控えめなナビ(戻る ∨ + 中央に日付, 12.5px 灰)。本文エリアは横 28px パディング、本文 15px/行間2.05。

- **1i 執筆中**: ツールバー・装飾は一切出さない。H1 タイトル(22px/700)+ 本文段落。行末に 2px 幅のキャレット。
- **1j 選択ツールバー**: テキスト選択(ハイライト `rgba(28,27,26,.14)` + 両端に墨のセレクションハンドル: 縦2px線 + 11px 円)。選択範囲の上 52px に白のフローティングツールバー(角丸12px, 影 `0 8px 26px rgba(0,0,0,.14)`): `本文 | H1 H2 H3 | ☑チェックリスト リスト …`。アクティブ項目(H2)は墨地に反転。同画面に他ブロック例: チェックリスト(チェック済みは打ち消し線+灰)、`img` プレースホルダ(45°ストライプ地 + ラベル「img: 夕焼けの写真」)、`details`(枠線カード + ▶ + 「病院メモ(たたんでおく)」)。→ **対応 HTML タグ: img / details。自前ストレージは持たないため画像アップUIは最小限**(URL 参照 or 端末写真の埋め込み想定)。
- **1k ブロック並び替え**: 長押しで drag & drop。各ブロック左に 6点ドラッグハンドル(掴んでいる行は墨、他は `#C7C6C2`)。ドラッグ中の行は白カード + 大きい影 + `rotate(-1.2deg) scale(1.02)`。挿入位置に 2.5px 墨のインジケータライン。ブロック単位は 見出し / 段落 / section / checklist。

### 5. テンプレート
- **1l 一覧**: ナビ「テンプレート」。「今日はどの紙に書きますか。」各テンプレはカード(タイトル + シェブロン + mono の markdown プレビュー)。例: 白紙 / 朝の3行 / 一日の振り返り / 旅の記録。末尾に「＋ 新しいテンプレート」。プレビュー内に `{{date}}` `{{weather}}` `{{place}}` 等の変数。
- **1m 変数入力**: テンプレ選択後のボトムシート。ドラッグハンドル + 「『一日の振り返り』から作成」+「埋めた言葉が、そのまま本文に入ります。」各変数フィールド(`{{date}}` は「自動」バッジ付きで自動補完、他は入力)。下に生成後の markdown プレビュー(くぼみ地)。主ボタン「この内容ではじめる」。**`{{変数}}` 記法をサポート**。

### 6. テーマ設定(1n)
ナビ「テーマ」。上部にライブプレビューカード(選択中の紙色地に見出し+本文)。**紙の色**(丸スウォッチ5種, 選択は墨枠+チェック)、**背景画像**(「写真から選ぶ ›」/「なし」)、末尾に注記「テーマはこの端末の中だけに保存されます。」。**外観トグル(ライト/ダーク)は無し** — ライト固定。

### 7. 復元フロー(1p)
新しい端末で日記を取り戻す。「おかえりなさい。」12スロットのグリッド(順番入力)。入力中スロットは墨枠+カーソル、以降は空。下にオートコンプリート候補チップ(amber, amount, amuse…)。「大文字・小文字は気にしなくて大丈夫です」。復元ボタンは全入力まで disabled。

### 8. サブスク訴求 / ペイウォール(1q)
「Nikki Plus」。右上に×クローズ。ロゴ + 「Nikki Plus」。「どの端末でも、続きから書けるように。」特典3件(チェック + タイトル + 説明): **複数端末で同期** / テーマを増やす / テンプレート無制限。料金プラン2枚(月ごと ¥300 / 年ごと ¥3,000 = ¥250/月, 年額に「2ヶ月ぶんお得」バッジ + 墨枠強調)。**訴求軸はデバイス数・同期**。脚注「同期中も、内容は暗号化されたままです。わたしたちが読めないことは、変わりません。」主ボタン「Nikki Plus をはじめる」。フッタ: 購入の復元 / 利用規約 / プライバシー。※有料機能は検討中のため構成は差し替え可能。

### 9. 設定(1r)
ナビ「設定」。iOS 標準のグループ化リスト形式。
- **書くこと**: 既定のテンプレート(一日の振り返り) / 自動ロック(5秒)
- **鍵**: Face ID で解除(トグル ON) / パスキー(登録済み) / 復元フレーズをたしかめる
- **外観**: テーマ(生成) / 文字の大きさ(標準) ← ダーク項目は無し
- **データ**: Markdown で書き出す / Nikki Plus(未加入)
- フッタ「Nikki 1.0.0 — あなたの日記は、この端末の中に。」

## Interactions & Behavior
- **自動ロック**: 5秒無入力でロック画面へ。生体認証(Face ID/Touch ID/passkey)解除後、直前の画面・スクロール位置・カーソル位置に復帰。
- **一覧の切替**: セグメントコントロールでリスト↔カレンダーを即時切替(状態保持)。
- **エディタツールバー**: テキスト選択時のみフェードイン。選択解除で消える。書いている最中は完全に非表示(「書く邪魔をしない」)。
- **ブロック並び替え**: 長押し(~400ms)でドラッグ開始 → ハプティック + 浮き上がり演出 → ドロップで確定。
- **テンプレート変数**: `{{date}}` は作成時刻から自動補完、その他はシート上で入力してから本文生成。
- **ペイウォール**: 各特典/プランはタップで選択。購入は StoreKit(App 内課金)想定。
- **オンボ確認(1d)**: 3単語すべて正しく選ぶまで「確認する」を無効。
- トランジション: iOS 標準の push/modal に準拠。過度なアニメーションは避け「静けさ」を保つ。

## State Management
- `isLocked` / `lastRoute`(復帰用の直前画面 + スクロール/カーソル位置)
- `homeView`: `'list' | 'calendar'`
- `entries[]`(端末内・暗号化ストア): date, title, blocks[](type: heading/paragraph/section/checklist/img/details), createdAt, updatedAt
- エディタ: `selection`(range)→ ツールバー表示制御、`draggingBlockId`
- `mnemonic`(12語, 端末外に出さない)、`biometricEnrolled`, `passkeyRegistered`
- `theme`: paperColor, backgroundImage(端末ローカル保存)
- `subscription`: none | monthly | yearly
- **データ取得**: サーバは暗号文の同期(Plus)のみ。復号鍵は端末内。開発者は平文にアクセス不可。

## Assets
- **フォント**: Google Fonts「Zen Kaku Gothic New」(400/500/700)。実装では同梱 or システムフォント代替。
- **アイコン**: すべてインライン SVG のラインアイコン(ペン/南京錠/虫眼鏡/Face ID/検索/人物/シェブロン/6点ドラッグ/チェック/リスト/×)。SF Symbols への置換可(pencil, lock, magnifyingglass, faceid, person.crop.circle, chevron.*, line.3.horizontal, checkmark, list.bullet, xmark)。
- **画像**: 日記内 `img` は自前ストレージを持たない方針。アップロード UI は最小限。ロゴ「日」はテキスト+角丸枠で表現(専用アセット不要)。

## Files
- `Nikki iOS.dc.html` — 全 iOS 画面のデザインリファレンス(HTML/React Design Component)。ブラウザで直接開ける。各画面は `data-screen-label` と `id`(1a〜1s)で識別。
- `ios-frame.jsx` — プレビュー用の iPhone フレーム(実装対象外のスキャフォールド)。
- `support.js` — Design Component ランタイム(実装対象外)。

## 注意

- 配色はほぼ無彩色。ブランドカラーで塗らず、装飾はユーザーのテーマ機能に委ねる。
- Web / macOS 版は本ハンドオフ対象外(iOS のデザインシステムを踏襲して今後展開)。
