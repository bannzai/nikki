# Handoff: Nikki — macOS 日記アプリ UI

> iOS 版ハンドオフ(`README.md`)と **同一のデザインシステム**(カラー / タイポ / トークン / プロダクト思想)を共有する。本書は macOS 固有の**レイアウト作法**のみを記述する。トークンの詳細・各機能の意図・状態管理・アセットは `README.md` を必ず併読すること。

## Overview
Nikki の macOS 版。iOS の「白い紙と墨」をそのまま踏襲しつつ、デスクトップの作法に適応させる:**サイドバー + 複数ペイン**を基本形とし、設定・テーマは独立ウィンドウ、ロックはウィンドウ全体で表現する。ダークモードは対象外(ライト固定)。信号機(トラフィックライト)以外は無彩色を維持。

## About the Design Files
`Nikki macOS.dc.html` は **HTML で作成されたデザインリファレンス**。意図した見た目・レイアウトを示すプロトタイプであり、本番コードにそのままコピーするものではない。タスクは、これらを **ターゲットの macOS 環境(SwiftUI 推奨)で、その環境の確立されたパターンで再現すること**。`macos-window.jsx` はプレビュー用のウィンドウchromeスキャフォールドの参考(実装対象外)。実際の chrome は本 HTML 内で無彩色に自作している。

## Fidelity
**High-fidelity (hifi)。** 配色・タイポ・余白・角丸・インタラクションは iOS 版トークンに準拠。色は意図的にほぼ無彩色なので、macOS のセマンティックカラー(NSColor systemBackground / secondaryLabelColor 等)にマップして構わない。

## macOS 固有トークン / 作法
- **ウィンドウ**: 角丸 12px、影 `0 0 0 .5px rgba(0,0,0,.14), 0 26px 70px rgba(0,0,0,.30)`。
- **トラフィックライト**: 12px, gap 8px。左 `#FF5F57` / 中 `#FEBC2E` / 右 `#28C840`。サイドバー上端(高さ52pxのタイトルバー領域)左に配置。実装では OS 標準の window controls を使う。
- **サイドバー**: 幅 220px、地 `#F0EEE9`、右境界 `.5px rgba(0,0,0,.09)`。項目は高さ34px・角丸8px・font 13.5px、選択行は地 `#E2E0DA` + weight 700。セクション見出し(年など)は 11px/700 灰。実装は `NSSplitViewController` / SwiftUI `NavigationSplitView` の sidebar 相当。
- **一覧カラム(中央)**: 幅 326px、地 `#F6F4F0`、右境界 `.5px`。選択中の項目のみ白カード(角丸10px + 微影)、非選択は地のまま。上端に検索フィールド(地 `#E9E7E1`, 高さ30px, 角丸8px)。
- **エディタペイン(右)**: 可変幅、地 `#FAFAF9`、本文は左右パディング 64〜76px でコラム幅を絞る。上端右にツールバーアイコン(戻る/画像/共有相当は無し=共有機能なし)、下端に 34px のステータスバー(文字数・「🔒 この端末の中で暗号化 · 自動保存」)。
- **各ペインのタイトルバー高**: 52px(トラフィックライト行と揃える)。

## Screens / Views

### 2a メインウィンドウ — 3ペイン(1180×760)
`サイドバー(220) | 時系列一覧(326) | エディタ(可変)`。
- サイドバー: すべての日記(選択) / カレンダー / テンプレート、区切って「2026」配下に 月 + 件数(7月 5, 6月 12…)、最下部に「設定」。各項目に 15px ラインアイコン。
- 一覧: 月見出し配下にエントリ行(タイトル 14px/700 + 日付 mono + 抜粋2行 clamp)。選択行のみ白カード。
- エディタ: 日時キャプション → H1 タイトル(30px/700)→ 本文(16px/2.1)→ H2「買ったもの」→ チェックリスト。下端ステータスバー。

### 2b カレンダー表示(1180×760)
中央〜右を1枚のペインに統合した月ビュー(サイドバーの「カレンダー」選択時)。
- ヘッダ: 「2026年7月」+ ‹ 今日 › ナビ + 右端に 48px 墨丸の新規作成ボタン(ペンSVG)。
- グリッド: 7列 × 可変行、セル境界 `.5px rgba(0,0,0,.05)`。各セルに日付(未来日は `#C7C6C2`)+ 書いた日はタイトルチップ(地 `#EDEBE6`, 10.5px, 省略記号)。今日(18)は 22px 墨丸で反転 + タイトルチップも墨地反転。

### 2c エディタ選択フローティングツールバー(900×640)
常設バー無し。テキスト選択時のみ、選択範囲の上 54px に白のフローティングツールバー(角丸12px, 影 `0 10px 30px rgba(0,0,0,.16)`): `本文 | H1 H2 H3 | ☑ リスト …`、アクティブ(H2)は墨地反転。選択テキストは `rgba(28,27,26,.14)` ハイライト。`details` ブロック例(▶ + 折りたたみラベル)も表示。→ 対応タグ img / details。

### 2d テンプレート新規作成シート(900×640)
親ウィンドウにディム(`rgba(20,19,18,.14)`)を敷いた上の中央シート(幅560, 角丸14, 影 `0 30px 80px rgba(0,0,0,.4)`)。左にテンプレート一覧(白紙/朝の3行/一日の振り返り[選択]/旅の記録/＋新規)、右に変数フィールド。`{{date}}` は「自動」バッジ付き自動補完、他は入力(`{{weather}}` `{{mood}}`)。フッタに キャンセル / 作成(墨ボタン)。**`{{変数}}` 記法対応。**

### 2e 設定ウィンドウ(620×540)
macOS 標準の**ツールバータブ式** Preferences。上部78pxのツールバーにタブ(一般[選択]/鍵/外観/データ)、各タブは 20px アイコン + 11px ラベル。本文はラベル右寄せ 150px + コントロールの2カラム(既定テンプレート、自動ロック、Touch ID トグル、復元フレーズ、Markdown 書き出し、Nikki Plus)。**外観タブにダーク項目なし。**

### 2f テーマウィンドウ(620×540)
上端52pxタイトルバー中央に「テーマ」。ライブプレビューカード → 紙の色スウォッチ5種(白/生成[選択]/薄鼠/青磁/桜鼠)→ 背景画像(＋追加 / なし[選択])→ 注記「テーマはこの端末の中だけに保存されます。」**外観(ライト/ダーク)トグルなし。**

### 2g ロック(620×540)
ウィンドウ全体。背景に本文スケルトンを `blur(8px) opacity .5` で表示。中央に 66px 南京錠円 + 「鍵をかけておきました」+ pill ボタン「Touch ID で開く」+「解除すると、さっきの続きに戻ります」。5秒無操作で自動ロック、生体/passkey 解除後は直前の状態へ復帰。

## Interactions & Behavior(macOS 固有の補足)
- サイドバー項目クリックで中央/右ペインの内容を切替(list ↔ calendar)。
- 一覧の行選択でエディタペインが即時にそのエントリを開く(3ペイン連動)。
- 設定・テーマは独立ウィンドウ(⌘, で設定)。テンプレート作成はシート(sheet)。
- ウィンドウリサイズ時、サイドバー/一覧カラムは固定幅、エディタが伸縮。最小幅ではカラムを段階的に折りたたむ想定。
- キーボード: ⌘N 新規、⌘F 検索、選択 + ⌘1/2/3 で H1/H2/H3。
- その他(自動ロック挙動・状態・データモデル・思想)は iOS 版 README と共通。
