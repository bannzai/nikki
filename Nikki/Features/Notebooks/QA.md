## 1. ノートの作成

- [x] **設定からノート一覧へ入れる**: 設定の「ノート」から一覧が開き、いま持っているノートが並ぶ
  - 自動化: manual（設定からの遷移と一覧の内容を目視で確認する）
- [x] **新しいノートを作れる**: 一覧末尾の「＋ 新しいノート」から名前と書き出しを入力して「作成」すると、ノートが一覧の末尾に増える
  - 自動化: manual（作成フォームの入力から一覧への反映までを実操作で確認する）
  - 「Daily reflection」を作ると一覧の末尾に増えた
- [x] **名前が空のままでは作られない**: 名前を空にして「作成」を押しても、ノートは増えず作成フォームのまま留まる
  - 自動化: manual（空入力での作成操作の結果を目視で確認する）
  - 名前が placeholder のまま「Create」を押しても作成フォームに留まり、一覧は増えなかった
- [ ] **空白だけの名前では作られない**: 名前に空白文字だけを入れて「作成」を押しても、ノートは増えず作成フォームのまま留まる
  - 自動化: manual（空白のみの入力での作成操作の結果を目視で確認する）
  - ⏭️ スキップ: 今回の QA セッションでは空のままの入力のみ実施。空白だけの名前は次回 QA で確認する

## 2. ノートの編集と削除

- [x] **名前と書き出しを編集できる**: 一覧の行から編集画面に入り、名前と書き出しを書き換えて戻ると、一覧の表示と新規日記の書き出しに変更が反映される
  - 自動化: manual（編集後の一覧表示と、次の新規作成の中身を目視で確認する）
  - 名前の変更が一覧に反映され、書き出しへ追記した行がエディタのノート選択と新規日記の本文にも反映された
- [ ] **名前は空にできない**: 名前を空にして画面を離れると、元の名前のまま残る
  - 自動化: manual（空入力後の一覧表示を目視で確認する）
  - ❌ 失敗: 名前「Daily reflection」を 1 文字ずつ削除して空にし、戻るで画面を離れると、元の名前ではなく最後に入力された非空の値「D」がノート名として残った。再現手順: 設定 > Notebooks > ノートの行 > 名前欄でバックスペースを 16 回以上送る > 戻る > 一覧の名前を見る。原因は NotebookEditPage.setName が空文字だけを弾き、途中の 1 文字の状態は書き戻すため。無名のノートは作られないので実害は小さいが、項目の期待「元の名前のまま残る」とは一致しない。まとめて選択して一括削除した場合は期待どおりになる可能性があるが、WDA から選択メニューを出せず未確認。issue: https://github.com/bannzai/nikki/issues/79
- [x] **最後の1冊は削除できない**: ノートが1冊しかないとき、編集画面に「ノートを削除」が出ない。2冊以上にすると出る
  - 自動化: manual（ノートの冊数を変えて編集画面を目視で確認する）
  - ノートが 3 冊・2 冊のときは編集画面に「Delete notebook」があり、1 冊にすると消えた
- [x] **削除しても日記は残る**: 「ノートを削除」から確認ダイアログを経て削除すると、そのノートと書き出しは一覧から消え、そのノートで書いた日記はホームの一覧に残る
  - 自動化: manual（削除の連鎖は NikkiTests/JournalNotebookTests.swift が検証済み。ホームに日記が残ることは目視で確認する）
  - 「Daily reflection」で書いた日記 2 件を含む 3 件が、ノート削除後もホームの一覧に残った

## 3. エディタからのノートの選び直し

- [x] **白紙の日記はそのまま置き換わる**: まだ何も書いていない日記でノートを選ぶと、確認なしにそのノートの書き出しに置き換わってエディタへ戻る
  - 自動化: manual（選択から復帰までの流れを実操作で確認する）
  - ここでの「白紙」はタイトルも本文も空の日記を指す (NotebookListPage.select)。書き出しを持つ既定ノートから作った日記はタイトルに日付が入るため、何も打っていなくても確認アラートが出る。書き出しが空のノートから作った日記で確認なしの置き換えを確認した
- [x] **書きかけの日記は確認してから置き換わる**: すでに入力がある日記でノートを選ぶと、書いた内容が消える旨のアラートが出る。「キャンセル」なら内容がそのまま残り、「置き換える」なら書き出しに置き換わる
  - 自動化: manual（アラートの文言と、キャンセル・実行それぞれの結果を目視で確認する）
  - 「Cancel」では入力した本文がそのまま残り、「Replace」では選んだノートの書き出しに置き換わった
- [x] **選んだノートが次回も使われる**: ノートを選んだあとホームへ戻って新しい日記を作ると、前回選んだノートの書き出しで始まる
  - 自動化: manual（選択後の新規作成の中身を目視で確認する）
