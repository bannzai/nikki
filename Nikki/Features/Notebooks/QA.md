## 1. テンプレートの作成

- [x] **設定からテンプレート一覧へ入れる**: 設定の「テンプレート」から一覧が開き、いま持っているテンプレートが並ぶ
  - 自動化: manual（設定からの遷移と一覧の内容を目視で確認する）
  - 設定 > Templates から管理一覧が開き、Blank page と作成した Morning notes が並んだ
- [x] **新しいテンプレートを作れる**: 一覧末尾の「＋ 新しいテンプレート」から名前と書き出しを入力して「作成」すると、テンプレートが一覧の末尾に増える
  - 自動化: manual（作成フォームの入力から一覧への反映までを実操作で確認する）
  - エディタのテンプレート一覧 (設定の管理一覧と同じフォーム) から「Morning notes」を作成し、一覧の末尾に増えた
- [ ] **名前が空のままでは作られない**: 名前を空にして「作成」を押しても、テンプレートは増えず作成フォームのまま留まる
  - 自動化: manual（空入力での作成操作の結果を目視で確認する）
  - ⏭️ スキップ: 今回 (2026-08-22) は用語・導線変更 (issue #82) の再確認を優先。ロジック自体は変更していないため次回 QA で確認する
- [ ] **空白だけの名前では作られない**: 名前に空白文字だけを入れて「作成」を押しても、テンプレートは増えず作成フォームのまま留まる
  - 自動化: manual（空白のみの入力での作成操作の結果を目視で確認する）
  - ⏭️ スキップ: 前回 (2026-08-21) から未実施のまま。次回 QA で確認する

## 2. テンプレートの編集と削除

- [ ] **名前と書き出しを編集できる**: 一覧の行から編集画面(「テンプレートの編集」)に入り、名前と書き出しを書き換えて戻ると、一覧の表示と新規日記の書き出しに変更が反映される
  - 自動化: manual（編集後の一覧表示と、次の新規作成の中身を目視で確認する）
  - ⏭️ スキップ: 編集画面の表示 (Edit template / Name / Content) は確認したが、書き換えの反映までは今回未実施。次回 QA で確認する
- [x] **名前は空にできない**: 名前を空にして画面を離れると、元の名前のまま残る
  - 自動化: NikkiUITests/NotebookEditUITests.swift（1文字ずつ削除して離脱するイベント列を実イベントで検証する。issue #79）
  - 2026-08-22 ローカル iOS Simulator (iOS 26.5) で NotebookEditUITests が pass (文言をテンプレート用語に追随後)
- [x] **最後の1件は削除できない**: テンプレートが1件しかないとき、編集画面に「テンプレートを削除」が出ない。2件以上にすると出る
  - 自動化: manual（テンプレートの件数を変えて編集画面を目視で確認する）
  - 2件のとき編集画面に「Delete template」があり、1件に減らすと消えた
- [x] **削除しても日記は残る**: 「テンプレートを削除」から確認ダイアログを経て削除すると、そのテンプレートは一覧から消え、そのテンプレートで書いた日記はホームの一覧に残る
  - 自動化: manual（削除の連鎖は NikkiTests/JournalNotebookTests.swift が検証済み。ホームに日記が残ることは目視で確認する）
  - 「Morning notes」で書いた日記2件が、テンプレート削除後もホームの一覧に残った

## 3. エディタからのテンプレートの選び直し

- [ ] **白紙の日記はそのまま置き換わる**: まだ何も書いていない日記でテンプレートを選ぶと、確認なしにそのテンプレートの書き出しに置き換わってエディタへ戻る
  - 自動化: manual（選択から復帰までの流れを実操作で確認する）
  - ここでの「白紙」はタイトルも本文も空の日記を指す (NotebookListPage.select)。書き出しを持つ既定テンプレートから作った日記はタイトルに日付が入るため、何も打っていなくても確認アラートが出る
  - ⏭️ スキップ: 書き出しを空にしたテンプレートを作っての確認は今回未実施。次回 QA で確認する
- [x] **書きかけの日記は確認してから置き換わる**: すでに入力がある日記でテンプレートを選ぶと、書いた内容が消える旨のアラートが出る。「キャンセル」なら内容がそのまま残り、「置き換える」なら書き出しに置き換わる
  - 自動化: manual（アラートの文言と、キャンセル・実行それぞれの結果を目視で確認する）
  - 「Cancel」では本文がそのまま残り、「Replace」では選んだテンプレートの書き出し ({{date}} は日記の日付) に置き換わった
- [x] **選んだテンプレートが次回も使われる**: テンプレートを選んだあとホームへ戻って新しい日記を作ると、前回選んだテンプレートの書き出しで始まる
  - 自動化: manual（選択後の新規作成の中身を目視で確認する）
  - エディタで「Morning notes」を選んだあと、設定の「Default template」が Morning notes になり、新規日記が「August 22, 2026 / - One good thing」で始まった

## 4. 既定のテンプレート

- [x] **いま使われるテンプレートがわかる**: 設定の「既定のテンプレート」を開くと、新規日記に使われるテンプレートにチェックが付く (一度も選んでいないときは一覧の先頭のテンプレート)
  - 自動化: manual（チェックの位置を目視で確認する）
  - 設定の「既定のテンプレート」はテンプレートが 2 件以上のときだけ出る (SettingsPage)
  - 設定 > Default template で、既定の Morning notes にチェックが付いていた
- [ ] **選び直すと新規日記の書き出しが変わる**: 別のテンプレートを選んでからホームで日記を作ると、選んだテンプレートの書き出しで始まる

  - ⏭️ スキップ: エディタからの選択で既定が変わり新規日記に反映されることは確認済み (項目「選んだテンプレートが次回も使われる」)。この設定画面からの選び直し操作は今回未実施。次回 QA で確認する
