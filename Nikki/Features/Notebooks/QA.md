## 2. テンプレートの編集と削除

- [ ] **名前と書き出しを編集できる**: 一覧の行から編集画面(「テンプレートの編集」)に入り、名前と書き出しを書き換えて戻ると、一覧の表示と新規日記の書き出しに変更が反映される
  - 自動化: manual（編集後の一覧表示と、次の新規作成の中身を目視で確認する）
  - ⏭️ スキップ: 編集画面の表示 (Edit template / Name / Content) は確認したが、書き換えの反映までは今回未実施。次回 QA で確認する
- [x] **名前は空にできない**: 名前を空にして画面を離れると、元の名前のまま残る
  - 自動化: NikkiUITests/NotebookEditUITests.swift（1文字ずつ削除して離脱するイベント列を実イベントで検証する。issue #79）
  - 2026-08-22 ローカル iOS Simulator (iOS 26.5) で NotebookEditUITests が pass (文言をテンプレート用語に追随後)
- [x] **最後の1件まで削除できる**: テンプレートが1件しかないときでも編集画面に「テンプレートを削除」が出て、削除すると一覧が空になる (既定のテンプレートは一覧の「既定のテンプレートを復元」で戻せる)
  - 自動化: manual（1件の状態で編集画面の削除行と削除後の一覧を目視で確認する）
  - 2026-08-22 ローカル iOS Simulator で、1件だけの白紙を編集画面から削除でき、一覧が空(復元行のみ)になった (https://pub-7f3469dd3e2e445b9b8ec2d1381b5ea8.r2.dev/bannzai/nikki/20260822/ff75605a-d71a-4c89-85dd-2c55900c1196.png)

  - 「Morning notes」で書いた日記2件が、テンプレート削除後もホームの一覧に残った

## 3. エディタからのテンプレートの選び直し

- [ ] **白紙の日記はそのまま置き換わる**: まだ何も書いていない日記でテンプレートを選ぶと、確認なしにそのテンプレートの書き出しに置き換わってエディタへ戻る
  - 自動化: manual（選択から復帰までの流れを実操作で確認する）
  - ここでの「白紙」はタイトルも本文も空の日記を指す (NotebookListPage.select)。書き出しを持つ既定テンプレートから作った日記はタイトルに日付が入るため、何も打っていなくても確認アラートが出る
  - ⏭️ スキップ: 書き出しを空にしたテンプレートを作っての確認は今回未実施。次回 QA で確認する
- [x] **書きかけの日記は確認してから置き換わる**: すでに入力がある日記でテンプレートを選ぶと、書いた内容が消える旨のアラートが出る。「キャンセル」なら内容がそのまま残り、「置き換える」なら書き出しに置き換わる
  - 自動化: manual（アラートの文言と、キャンセル・実行それぞれの結果を目視で確認する）
  - 「Cancel」では本文がそのまま残り、「Replace」では選んだテンプレートの書き出し ({{date}} は日記の日付) に置き換わった
- [x] **選んだテンプレートが次回も使われる**: テンプレートを選んだあとホームへ戻って新しい日記を作ると、前回選んだテンプレートの書き出しで始まる
  - 自動化: manual（選択後の新規作成の中身を目視で確認する）
  - エディタで「Morning notes」を選んだあと、新規日記が「August 22, 2026 / - One good thing」で始まった (2026-08-22 の変更で設定の「Default template」表示は廃止。選択の記憶自体は変わらない)

## 4. 既定のテンプレートの復元とすべて削除

設定の「既定のテンプレート」行(選択画面 NotebookDefaultPage)は廃止し、テンプレート管理一覧に統合した。新規日記に使われるテンプレートは、エディタのテンプレート一覧で最後に選んだもの(未選択なら先頭)のまま変わらない。

- [x] **すべてのテンプレートを削除できる**: 一覧の「すべてのテンプレートを削除」から確認ダイアログを経て削除すると、一覧が空になり、テンプレートで書いた日記はホームに残る
  - 自動化: manual（削除ダイアログと削除後の一覧を目視で確認する。日記が残ることは NikkiTests/JournalNotebookTests.swift の deleteAllJournalNotebooks テストが検証済み）
  - 2026-08-22 ローカル iOS Simulator と macOS (Debug) の両方で、確認ダイアログ → 一覧が空(復元行のみ)になることを確認 (https://pub-7f3469dd3e2e445b9b8ec2d1381b5ea8.r2.dev/bannzai/nikki/20260822/143b69a6-ea56-4663-8293-cf3018d2481f.png, https://pub-7f3469dd3e2e445b9b8ec2d1381b5ea8.r2.dev/bannzai/nikki/20260822/935180ca-ddb1-41a8-b696-a23ffeddeb67.png)
- [x] **既定のテンプレートを復元できる**: 一覧の「既定のテンプレートを復元」で初回シードと同じ白紙({{date}})が一覧の末尾に入り、もう一度押しても重複しない(冪等)
  - 自動化: manual（復元後の一覧と、再度押したときに増えないことを目視で確認する）
  - 2026-08-22 ローカル iOS Simulator (復元 + 冪等) と macOS (復元) で確認 (https://pub-7f3469dd3e2e445b9b8ec2d1381b5ea8.r2.dev/bannzai/nikki/20260822/ad4bc088-80cf-4543-819a-7692369ba7b7.png)
- [x] **削除した空の状態は再起動で復活しない**: すべて削除したあとアプリを再起動しても、テンプレートは空のまま(初回シードが再実行されない)
  - 自動化: manual（削除 → 再起動 → 一覧を目視で確認する）
  - 2026-08-22 ローカル iOS Simulator で、全削除後にアプリを terminate → 再起動してもテンプレートが空のままだった (UserDefaults の notebooksSeeded で再シードを抑止)
