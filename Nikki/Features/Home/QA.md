  - 自動化: manual（アプリの再起動をまたいだ保持を目視で確認する）
- [ ] **日記のある日と今日がひと目でわかる**: 日記のある日には日付の下に点が付き、今日は反転した円で示され、未来の日付は薄く表示される

- [ ] **日付から日記を開ける**: 日記のある日をタップするとその日の日記のエディタが開き、日記のない日はタップしても何も起きない

## 3. 検索

- [ ] **タイトルと本文から絞り込める**: 検索バーに入力すると、タイトルまたは本文にその語を含む日記だけが残る。大文字と小文字は区別しない
  - 自動化: manual（絞り込みの判定は NikkiTests/JournalEntryTests.swift が検証済み。検索バーの入力から一覧へ反映されることは目視で確認する）
- [ ] **一致しないときの案内**: どの日記にも一致しない語を入れると「見つからない」旨の案内が出て、文字を消すと元の全件に戻る
  - 自動化: manual（空状態の文言と復帰を目視で確認する）
- [ ] **カレンダー表示でも絞り込みが効く**: 検索中にカレンダーへ切り替えると、一致した日記のある日にだけ点が残る
  - 自動化: manual（絞り込み後のグリッドを目視で確認する）
- [ ] **⌘F で検索欄にカーソルが入る**: ハードウェアキーボードのある環境 (macOS / iPad) で ⌘F を押すと検索欄にフォーカスが移り、そのまま入力できる
