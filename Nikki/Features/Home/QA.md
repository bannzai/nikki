## 2. カレンダー表示

- [x] **リストとカレンダーを切り替えられる**: 上部のセグメントで表示が切り替わり、アプリを起動し直しても最後に選んだ表示のまま開く
  - 自動化: manual（アプリの再起動をまたいだ保持を目視で確認する）
  - カレンダーを選んだ状態でアプリを終了・再起動してもカレンダー表示で開いた
- [ ] **日記のある日と今日がひと目でわかる**: 日記のある日には日付の下に点が付き、今日は反転した円で示され、未来の日付は薄く表示される
  - 自動化: manual（点・反転円・薄い文字の描画を目視で確認する）
  - ⏭️ スキップ (一部のみ確認): 今日 (21) が反転した円で示されること・未来の日付が薄いことは確認した。日記のある日の点は、今日のセルが反転円で点を描かない実装 (HomeCalendarDayCell) のうえ、UI から過去日の日記を作れないため観測できない
- [x] **前後の月へ移動できる**: 月名の左右のシェブロンで前後の月へ移動し、その月の日付と点の付き方が入れ替わる
  - 自動化: manual（月送り後のグリッドの内容を目視で確認する）
  - シェブロンで August 2026 → September 2026 → (戻る×2) July 2026 → August 2026 と移動できた
- [x] **日付から日記を開ける**: 日記のある日をタップするとその日の日記のエディタが開き、日記のない日はタップしても何も起きない
  - 自動化: manual（タップの反応の有無を実機操作で確認する）
  - 日記のある 21 をタップするとエディタが開き、日記のない 18 をタップしてもカレンダーのままだった
- [x] **今日の日記のプレビューが出る**: 今日を含む月を表示していて今日の日記があるとき、グリッドの下に日付・時刻・タイトル・抜粋のカードが出て、タップでその日記が開く。前後の月へ移動している間はカードが出ない
  - 自動化: manual（今日の日記の有無と表示月を変えながら目視で確認する）
  - カードのタップでその日記が開くこと、前後の月へ移動している間はカードが出ないことも確認

## 3. 検索

- [x] **タイトルと本文から絞り込める**: 検索バーに入力すると、タイトルまたは本文にその語を含む日記だけが残る。大文字と小文字は区別しない
  - 自動化: manual（絞り込みの判定は NikkiTests/JournalEntryTests.swift が検証済み。検索バーの入力から一覧へ反映されることは目視で確認する）
  - 本文に小文字で「sunny」を含む日記が、大文字「SUNNY」の検索で 1 件だけ残った
- [x] **一致しないときの案内**: どの日記にも一致しない語を入れると「見つからない」旨の案内が出て、文字を消すと元の全件に戻る
  - 自動化: manual（空状態の文言と復帰を目視で確認する）
  - 「zzzz」で「Nothing found. / Try searching with different words.」が出て、文字を消すと 3 件全部に戻った
- [ ] **カレンダー表示でも絞り込みが効く**: 検索中にカレンダーへ切り替えると、一致した日記のある日にだけ点が残る
  - 自動化: manual（絞り込み後のグリッドを目視で確認する）
  - ⏭️ スキップ: UI から過去日の日記を作れず、日記が今日 1 日に集中する。今日のセルは反転円で点を描かないため、絞り込みで点が減ることを観測できない
- [ ] **⌘F で検索欄にカーソルが入る**: ハードウェアキーボードのある環境 (macOS / iPad) で ⌘F を押すと検索欄にフォーカスが移り、そのまま入力できる
  - 自動化: manual（ハードウェアキーボードのショートカットを実操作で確認する）
  - ⏭️ スキップ: リモート iOS Simulator にハードウェアキーボードを接続できないため ⌘F を発火できない

## 4. 日記の新規作成

- [x] **ペンボタンで日記ができてエディタが開く**: 右下のペンボタンを押すと今日の日付の日記が作られ、そのままエディタへ進む (書き出しを選ぶ画面は挟まらない)
  - 自動化: manual（ボタン操作からエディタへ進む流れを実操作で確認する）
  - 書き出しを選ぶ画面は挟まらず、そのままエディタが開いた
- [x] **既定のノートの書き出しが入っている**: 開いたエディタに既定のノートの書き出しが入っていて、{{date}} の位置が今日の日付表記になっている
