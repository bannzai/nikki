## Nikki
日記のサービスです。以下の特徴を持っています

- シンプル
- 簡易ながらユーザーで日記UIの装飾が可能
- 誰にもみられない安心設計
    - 5秒タイプがなかったらログイン/Face ID突破からやり直し
    - ロック解除後は最後に開いてた画面が開く
- 文章は自分の手で書いてこそ意味があるので、文章を書く補助機能などは一切無しです

## Editor
- フォーマットは自由です。ユーザーが自由に日記を書けます
- マークダウン互換があります
- Editor上ではマークダウンを便利に操作できる機能を提供します
  * sectionやchecklistをdrag & dropで順番を入れ替えることができます
  * H1,2,3 など文字の太さや装飾も変更できます
- GitHubのように一部のHTMLタグをサポートしたいです。imgやdetails
- テンプレート機能があります。あらかじめ用意したmarkdown形式のテンプレートファイルを用いて日記を新規作成ができます
    - 変数も使えます {{date}} と書くと、その部分は 2026-07-19 のような形式になります
- テーマが装飾できます。色や背景画像等を設定できます

## Security
- 5秒タイプされなかったら、ログイン/Face ID突破からやり直しです
- DB: Evoluを採用。ref: https://github.com/bannzai/nikki/issues/1
